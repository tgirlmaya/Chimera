# Identify

_1st-level, Divination (ritual)_

- **Casting time:** 1 minute unless cast as a ritual
- **Range:** Touch
- **Components:** V, S, M (a pearl worth 100+ GP)
- **Duration:** Instantaneous

You touch an object throughout the spell's casting. If the object is a magic item or some other magical object, you learn its properties and how to use them, whether it requires [Attunement](Compendium/Mechanics/CLI/Rules/variant-rules/attunement-xphb.md), and how many charges it has, if any. You learn whether any ongoing spells are affecting the item and what they are. If the item was created by a spell, you learn that spell's name.

If you instead touch a creature throughout the casting, you learn which ongoing spells, if any, are currently affecting it.

**Classes**: [Bard (College of Lore)](Compendium/Mechanics/CLI/lists/list-spells-classes-college-of-lore-xphb.md "subclass=XPHB;class=XPHB"); [Bard](Compendium/Mechanics/CLI/lists/list-spells-classes-bard.md); [Fighter (Eldritch Knight)](Compendium/Mechanics/CLI/lists/list-spells-classes-eldritch-knight-xphb.md "subclass=XPHB;class=XPHB"); [Rogue (Arcane Trickster)](Compendium/Mechanics/CLI/lists/list-spells-classes-arcane-trickster-xphb.md "subclass=XPHB;class=XPHB"); [Wizard (Diviner)](Compendium/Mechanics/CLI/lists/list-spells-classes-diviner-xphb.md "subclass=XPHB;class=XPHB"); [Wizard](Compendium/Mechanics/CLI/lists/list-spells-classes-wizard.md)
